⑤ 如果这里 ①② 都不动，按顺序看

  1. 系统「减弱动效」：Windows 设置 → 辅助功能 → 视觉效果 → 动画效果；iPhone 设置 → 辅助功能 → 动态效果 → 减弱动态效果；Android 开发者选项 → 动画时长缩放 或 辅助功能 → 移除动画。
  2. 浏览器扩展：任何「减少动画 / Reduce Motion / 省电」类扩展都会全局禁动画。
  3. 网页缓存：强制刷新（Windows Ctrl+F5；手机清一次站点数据）后重开。
② 是给上面这些情况准备的兜底：它不靠 CSS 动画，所以即使 ① 不动，app 里也应该仍然会动。
